# Gestor de Ventas e Inventario Express

## Descripción

Sistema de consola desarrollado en **C# con .NET 8** como proyecto final de la Unidad 1.

El programa funciona como un pequeño sistema de ventas e inventario para una tienda de barrio. Permite registrar productos, consultar el inventario, realizar ventas y consultar estadísticas de caja.

## Funcionalidades

* Registrar nuevos productos.
* Validar nombre, precio y cantidad de stock.
* Evitar productos duplicados.
* Consultar el inventario completo.
* Mostrar alertas cuando un producto tiene menos de 5 unidades.
* Registrar ventas.
* Aplicar un descuento del 10% a clientes frecuentes.
* Calcular IVA del 19%.
* Generar un ticket de venta.
* Actualizar automáticamente el stock.
* Consultar el total de ventas y dinero acumulado.
* Mostrar el promedio por venta.
* Mostrar el producto con mayor cantidad de unidades vendidas.
* Manejar entradas inválidas mediante validaciones.

Para ejecutar el proyecto se necesita tener instalado:

* .NET 8 SDK

## Ejecución del proyecto

Clonar el repositorio:

```bash
git clone URL_DEL_REPOSITORIO
```

Entrar a la carpeta del proyecto:

```bash
cd GestorVentasUnidad1
```

Compilar el proyecto:

```bash
dotnet build
```

Ejecutar el programa:

```bash
dotnet run
```

## Menú principal

El programa cuenta con las siguientes opciones:

1. Registrar nuevo producto.
2. Consultar inventario completo.
3. Registrar una venta.
4. Ver reporte de caja y estadísticas diarias.
5. Salir.
